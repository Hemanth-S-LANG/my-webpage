# Amazon Inspired Clone Project

## 🌟 Project Overview
This project is a front-end clone of the Amazon shopping website built using pure HTML and CSS. It focuses on recreating the familiar e-commerce layout with a dark top navigation bar, search area, category menu, hero banner, product cards, and a footer section. The goal was to practice modern web design, layout structuring, and responsive styling while mimicking the aesthetic of one of the most popular online shopping platforms.

The project includes the complete homepage design, giving a realistic shopping experience with product sections and a polished premium look.

---

## ✨ Features Included
- Amazon-style header with logo, location, search bar, language, account info, returns, and cart
- Dark navbar and category panel similar to Amazon's UI
- Search box with custom styling and hover interaction
- Promotional hero banner section
- Multiple product cards with category images and "See more" links
- Clean shopping grid layout with cards for Fresh, Gym, Electronics, Deals, Fashion, Accessories, Beauty, Mobiles, Books, Home & Kitchen, and Computers
- Footer with multiple informational columns and links
- Hover effects on navigation items and category elements
- Use of Font Awesome icons for visual enhancement
- Professional color palette inspired by Amazon branding
- Fully custom styling through CSS for spacing, layout, and borders

---

## 🧩 HTML Components Used
The project was built primarily using standard HTML structure and semantic layout elements. Some of the important components used are:

- `div` tags for layout containers and sections
- `header` tag for the top navigation and menu area
- `footer` tag for the bottom information area
- `p` tags for text content like address, account details, and labels
- `img` tags for product and logo visuals
- `select` and `option` tags for dropdown elements
- `input` tag for the search field
- `a` tags for links to different product categories
- `ul` and `li`-style list-based content in the footer
- `i` tags with Font Awesome icons for cart, search, location, and menu icons

These elements help build the structure and visual hierarchy of the website.

---

## 🎨 CSS Features Used
The styling in the project demonstrates various CSS concepts and design techniques. Some of the main CSS features used are:

- `border` for outlines and UI separation
- `border-radius` for rounded search bar and boxes
- `background-color` for navbar, footer, and promotional sections
- `color` styling for text and link effects
- `display: flex` for alignment and layout management
- `justify-content` and `align-items` for centered alignment
- `hover` effects to create interactive UI states
- `background-image` to display category images and hero visuals
- `margin`, `padding`, and `width` for spacing and sizing
- `font-size`, `font-weight`, and `font-family` for typography
- `position` and `z-index` for layered sections and layout control
- `flex-wrap` for product card arrangement in rows
- `background-size` and `background-repeat` for image control
- `cursor: pointer` for interactive elements
- `transition`-like visual behavior using hover states for a smoother experience

The CSS creates the polished and visually appealing layout that makes the clone feel close to a real e-commerce homepage.
